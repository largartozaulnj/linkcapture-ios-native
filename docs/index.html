LinkCapture

Fonte oficial gratuita de atualizações para o AltStore Classic. Navegador nativo para iPhone, iOS 16 ou superior.

Adicionar ao AltStore Classic

Se o botão não abrir sua versão do AltStore, use o link compatível anterior ou copie a URL abaixo em Sources → +.

https://largartozaulnj.github.io/linkcapture-ios-native/source.json

  1. Adicione e confirme a fonte no AltStore Classic.
  2. Procure LinkCapture. Se já está instalado com a mesma conta/identidade, confira se aparece Atualizar em My Apps. Não desinstale o app para forçar associação.
  3. Revise a versão e autorize a instalação. Pode ser necessário AltServer no Windows para assinar; o catálogo não assina nem instala sozinho.
  4. No LinkCapture, abra Menu → Assinatura e Atualizações. Informe o vencimento mostrado no AltStore e autorize os lembretes locais.

A associação da instalação antiga à fonte e a preservação dos dados precisam ser conferidas no iPhone. O Bundle ID original é org.linkcapture.experimental; o AltStore pode acrescentar o identificador da sua equipe ao reassinar.
